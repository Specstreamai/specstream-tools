# SpecStream for Codex and ChatGPT

SpecStream is the live web data engine for teams and agents. Ask for a list in plain words,
get rows that match what you asked, with the page behind each fact, and read them in
Codex or ChatGPT. The plugin connects to the SpecStream MCP server at
https://api.specstream.ai/mcp and signs you in with your SpecStream account.

Add it to Codex from this repository:

    codex plugin marketplace add Specstreamai/specstream-tools

Then open /plugins in Codex, choose SpecStream and sign in. In ChatGPT, type @SpecStream
in a Work chat once the plugin is installed.

The files here are generated from the SpecStream source. Do not edit them by hand.
